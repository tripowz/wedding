# Сайт-приглашение Bekzod & Ferangiz

Стиль — как в видео: шёлк, атласные ленты, конверт с сургучом, открытка-арка, золото и бордо.
Языки: узбекский и русский. Ссылка сразу на русском: `…/?lang=ru`.

## Что где лежит
- `index.html` — страница.
- `css/style.css`, `css/fonts.css` — оформление и шрифты (Great Vibes, Forum, Cormorant Garamond).
- `js/config.js` — **все данные и тексты**: имена, дата, место, программа, правила, адрес для ответов.
- `js/main.js` — конверт, открытка, таймер, карта, музыка, форма.
- `js/satin.js`, `js/ribbons.js`, `js/bake.js` — шёлк, ленты, бумага, конверт, сургуч (рисуются в браузере).
- `assets/music.mp3` — «Over and Over», играет с 8,5 с.
- `google-apps-script/Code.gs` — приём ответов: Google Таблица + Telegram.
- `_archive/site-v2/` — прошлая версия сайта.

## Запуск на компьютере
```
python -m http.server 5500
```
Откройте http://localhost:5500. Пока адрес ответов не задан, форма работает в тестовом режиме (ничего не отправляет).

## Ответы гостей: Google Таблица + Telegram (≈10 минут)

### 1. Таблица и скрипт
1. Создайте новую Google Таблицу (sheets.new), назовите, например, «Гости — свадьба».
2. Меню **Расширения → Apps Script**. Удалите всё в редакторе и вставьте содержимое `google-apps-script/Code.gs`. Сохраните.

### 2. Бот в Telegram
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя (например, «BF Wedding») и логин (например, `bf_wedding_rsvp_bot`).
2. BotFather пришлёт **токен** — длинную строку вида `123456:ABC…`. Никому её не показывайте.
3. Откройте своего бота и нажмите **Start** (и попросите невесту сделать то же самое, если ей тоже нужны уведомления).
   Можно добавить бота в общий чат семьи — тогда напишите в чате любое сообщение.
4. В Apps Script: **Настройки проекта (шестерёнка) → Свойства скрипта → Добавить**:
   - `TG_TOKEN` = токен от BotFather.
5. Вернитесь в редактор, вверху выберите функцию **findChatIds** → **Выполнить** (Google попросит разрешения — разрешите).
   В журнале появятся строки `chat_id: …`.
6. Добавьте ещё одно свойство: `TG_CHAT_IDS` = нужные chat_id через запятую (например `123456789,987654321`).
7. Выберите функцию **testTelegram** → **Выполнить**. В Telegram должно прийти пробное сообщение.

### 3. Публикация скрипта
1. **Развернуть → Новое развертывание → тип «Веб-приложение»**.
2. «Выполнять от имени»: **Я**. «У кого есть доступ»: **Все**.
3. Нажмите «Развернуть» и скопируйте **URL веб-приложения** (заканчивается на `/exec`).
4. Вставьте его в `js/config.js` → `rsvpEndpoint: "https://script.google.com/macros/s/…/exec"`.

Каждый ответ гостя появится строкой в листе «Гости», а в Telegram придёт сообщение:
имя, придёт или нет, сколько человек, чья сторона, пожелание и общий итог («ответили 12 · придут 9 (24 чел.)»).
Если гость изменит ответ, в таблице появится новая строка с пометкой «Повторный ответ», а итог посчитается по последнему ответу.

> Если позже поменяете `Code.gs`: **Развернуть → Управление развертываниями → Изменить → Версия: новая** — адрес останется прежним.

## Публикация на Vercel
1. Зарегистрируйтесь на vercel.com (можно через GitHub).
2. Загрузите папку проекта как новый проект: Framework — **Other**, без сборки. Папки `video/` и `_archive/` в публикацию не попадут (см. `.vercelignore`).
3. Vercel выдаст адрес вида `bf-wedding.vercel.app` — его и рассылайте. Для русскоязычных гостей: `bf-wedding.vercel.app/?lang=ru`.

## Что поменять потом
- Тексты, программу, правила — `js/config.js`.
- Фото: дизайн рассчитан без фото; когда будут свои снимки, добавим блок-галерею в том же стиле.
