# Свадебное приглашение

Статический сайт (HTML + CSS + JS) без сборки. Анимации сделаны на GSAP, он подключается с CDN.

## Структура

```
index.html                 разметка
css/style.css              стили и палитра (переменные в :root)
js/config.js               ← ВСЕ данные: имена, дата, место, программа, фото, тексты UZ/RU
js/main.js                 логика и анимации
google-apps-script/Code.gs скрипт для Google Таблицы (RSVP)
assets/                    сюда кладём music.mp3 и свои фото
```

## Локальный запуск

```bash
python -m http.server 5500
```

Затем откройте http://localhost:5500

Ссылка с языком по умолчанию: `http://localhost:5500/?lang=ru` или `?lang=uz`.

## Что поменять перед свадьбой

Всё меняется в `js/config.js`:

1. **Имена, инициалы, дата, время, срок ответа** (`groom`, `bride`, `initials`, `date`, `rsvpDeadline`).
2. **Место**: название, адрес и координаты `lat`/`lon` (в Яндекс Картах: правый клик по точке → «Что здесь?»).
   Если нужны точные ссылки на карточку зала, добавьте в `venue`:
   ```js
   links: { yandex: "https://yandex.uz/maps/org/...", google: "https://maps.app.goo.gl/...", twogis: "https://2gis.uz/tashkent/firm/..." }
   ```
3. **Программа дня**: массив `program`.
   **Правила свадьбы**: массив `rules` (иконки: `clock`, `rings`, `note`, `piyola`, `phone`, `cake`).
4. **Фото**: положите файлы в `assets/photos/` и укажите пути, например `"assets/photos/hero.jpg"`.
   - `hero` раскрывается из арки на весь экран: нужен кадр, где пара в центре-вверху, ширина 1600+ px.
   - `gallery` (ротонда из арок): вертикальные 2:3, ширина ~800 px, вес до 300 КБ.
   - `venue` прячется под «стираемым» слоем, `hands` — фон блока RSVP.
5. **Музыка**: положите файл в `assets/music.mp3`. Пока файла нет, кнопка музыки скрыта.
6. **Превью ссылки** в Telegram: в `index.html` замените `og:image` и `og:title` (после деплоя нужен абсолютный URL картинки).

## RSVP → Google Таблица

1. Создайте Google Таблицу.
2. Меню **Расширения → Apps Script**, вставьте код из `google-apps-script/Code.gs`, сохраните.
3. **Начать развертывание → Новое развертывание** → тип **Веб-приложение**:
   - «Выполнять как»: **От моего имени**
   - «У кого есть доступ»: **Все**
4. Разрешите доступ, скопируйте URL веб-приложения (заканчивается на `/exec`).
5. Вставьте его в `js/config.js` → `rsvpEndpoint: "https://script.google.com/macros/s/.../exec"`.

Пока `rsvpEndpoint` пустой, форма работает в тестовом режиме: данные только выводятся в консоль браузера.
